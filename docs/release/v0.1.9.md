# Modern Emoji Picker 0.1.9 + Renderer 0.0.2

Public MVP release ออกแบบสำหรับ Windows 10/11 ประกอบด้วย Picker และ Chrome Renderer ซึ่งติดตั้งร่วมกันหรือเลือกใช้แยกกันได้ การทดสอบหลักของรุ่นนี้ทำบน Windows 10 Enterprise N 22H2 build 19045 ส่วน environment ที่ยังไม่ครอบคลุมบันทึกไว้ใน [ผล Qualification](../qualification/README.md)

## ไฟล์ดาวน์โหลด

- `Modern-Emoji-Picker-v0.1.9-setup-win-x64.exe` — ตัวติดตั้งเฉพาะผู้ใช้ปัจจุบัน แนะนำสำหรับผู้ใช้ทั่วไป
- `Modern-Emoji-Picker-v0.1.9-portable-win-x64.zip` — Portable แบบ self-contained
- `modern-emoji-renderer-0.0.2.zip` — Chrome Extension ต้องแตก ZIP และ Load unpacked
- `SHA256SUMS.txt` และ `modern-emoji-renderer-0.0.2.zip.sha256` — ค่า hash สำหรับตรวจไฟล์

## ติดตั้ง Picker

ดาวน์โหลดตัวติดตั้ง เปิดไฟล์และทำตามขั้นตอนโดยไม่ต้องใช้สิทธิ์ administrator หาก Classic Emoji Picker ยังทำงานอยู่ ให้ Exit จาก tray ก่อนเพื่อให้ `Win + .` ใช้ Modern ได้

ตัวติดตั้งยังไม่ได้ลงลายเซ็น Windows SmartScreen อาจแจ้งว่าไม่รู้จักผู้เผยแพร่ โปรดตรวจ SHA-256 ก่อนเปิด และไม่ต้องปิดระบบป้องกันของ Windows

## ติดตั้ง Renderer

แตก `modern-emoji-renderer-0.0.2.zip` ไปยังโฟลเดอร์ถาวร เปิด `chrome://extensions`, เปิด Developer mode แล้วกด Load unpacked เพื่อเลือกโฟลเดอร์ดังกล่าว จากนั้น refresh Instagram/TikTok

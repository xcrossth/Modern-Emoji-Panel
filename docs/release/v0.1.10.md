# Modern Emoji Picker 0.1.10 + Renderer 0.0.5

Patch release นี้แก้การส่ง supplementary Emoji เข้า Chromium page editor และรวมไฟล์ดาวน์โหลดของ Picker กับ Renderer ไว้ใน GitHub Release เดียวกัน

## ไฟล์ดาวน์โหลด

- `Modern-Emoji-Picker-v0.1.10-setup-win-x64.exe` — ตัวติดตั้งเฉพาะผู้ใช้ปัจจุบัน แนะนำสำหรับผู้ใช้ทั่วไป
- `Modern-Emoji-Picker-v0.1.10-portable-win-x64.zip` — Portable แบบ self-contained
- `modern-emoji-renderer-0.0.5.zip` — Chrome Extension ต้องแตก ZIP และ Load unpacked
- `SHA256SUMS.txt` และ `modern-emoji-renderer-0.0.5.zip.sha256` — ค่า hash สำหรับตรวจไฟล์
- `verification-report.md` — รายงานตรวจแพ็กเกจ Renderer 0.0.5

## การเปลี่ยนแปลงของ Picker

- แก้ Hybrid insertion ที่ Chrome page editor บางรุ่นแปลง UTF-16 surrogate pair จาก `KEYEVENTF_UNICODE` เป็น `U+FFFD`
- ใช้ Temporary Paste แบบ atomic สำหรับ supplementary sequence เมื่อ UI Automation ระบุ text edit target ใน Chrome accessibility framework จึงครอบคลุมทั้ง address bar และช่องพิมพ์เว็บ เช่น Instagram DM และ TikTok Chat
- คงเส้นทาง Keystroke สำหรับ native target, คง `Keystroke only` เป็น override และไม่เปลี่ยนค่าเริ่มต้น `pasteRestoreDelayMs` ที่ 250 ms
- เพิ่ม regression checks สำหรับ Chromium contenteditable, Chromium omnibox และ native edit

## Renderer 0.0.5

Renderer เป็นไฟล์เดียวกับรุ่น `renderer-v0.0.5` และยังรองรับ Instagram, TikTok, Facebook Messages/Inbox และ Messenger.com ตามเดิม Release นี้ไม่ได้เปลี่ยน source หรือพฤติกรรมของ Renderer

## Qualification

- maintainer ยืนยันด้วย A/B บน Chrome 152 ว่า Hybrid/Unicode keystroke ทำให้ช่องพิมพ์ IG และ TikTok ได้ `U+FFFD` ขณะที่ Paste always ส่ง sequence เดิมได้ถูกต้อง
- Temporary Paste ทำงานได้ในการทดสอบจริงที่ restore delay 50 ms บนเครื่องทดสอบ แต่ค่าเริ่มต้นยังเป็น 250 ms เพื่อความเข้ากันได้กับ target ที่ช้ากว่า
- automated qualification, package verification และ checksum ต้องผ่านก่อนอัปโหลด Release
